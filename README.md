# Soumitra Behera — Graphic Designer Portfolio

A responsive portfolio website built from the latest portfolio PDF supplied in this conversation.

## Preview
Open `index.html` in a modern browser. No build tools are required.

## Included
- Professional charcoal and gold visual identity
- Responsive desktop and mobile layout
- Profile portrait and About section
- 17 portfolio samples across four categories
- Working category filters
- Click-to-enlarge project previews
- Services and contact sections

## Publish on GitHub Pages
1. Extract the ZIP file.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the root of your GitHub repository.
3. In GitHub, go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select your main branch and `/ (root)`, then save.
5. GitHub Pages will publish the website.
